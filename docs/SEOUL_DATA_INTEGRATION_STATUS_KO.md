# 서울 도슨트 데이터 연결 상태

작성일: 2026-11-22

## 코드상 데이터 흐름

- **BigQuery:** 주소별 조사 후보를 조회하는 기존 모듈이 MCP 응답에 후보/출처 URL을 추가합니다. 후보를 승인 근거로 올리지 않습니다.
- **D1:** 장소 식별자와 건물·필지 링크, 원문 확인 및 승인 상태를 조회합니다. 이번 작업은 읽기 전용이고 마이그레이션을 실행하지 않았습니다.
- **R2:** 기존 아카이브 매체 저장소 결합은 유지됩니다. 이 작업에서 객체를 읽거나 쓰지 않았습니다.
- DB/환경 바인딩의 실제 Preview·Production 연결은 이 로컬 실행만으로 증명할 수 없습니다. 자격 증명이나 환경 접근이 없어 원격 D1 격리와 BigQuery/R2 연결 상태는 `미확인`입니다.

## 장소 관계 및 검토

장소 연결 조회는 공식 건물관리번호와 필지 PNU를 분리합니다. PNU만으로 개별 건물을 직접 식별하지 않고, 검토 대기 링크는 후보입니다. 7부 계획에는 승인된 관계만 직접 근거로 넣습니다. 좌표/거리나 이름만 일치한 후보는 직접 근거로 변환하지 않습니다.

## 원격 검증 및 데이터 보호

- Vercel Preview HTTP 실증: 이번 작업에서 수행하지 않음.
- Preview D1과 Production D1 분리 증명: 미확인.
- D1 migration 0006–0008 원격 적용: 수행하지 않음.
- BigQuery 쿼리 실연결: 미확인.
- R2 객체 접근: 미확인.
- Production, 데이터베이스, 저장된 미디어에는 변경을 수행하지 않음.

원격 검증은 Preview 전용 자격 증명과 Preview D1 식별자를 확보하고 Production과 다른 DB임을 먼저 확인한 뒤 진행해야 합니다.
