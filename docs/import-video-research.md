# 서울 역사 영상 엑셀 추가하기

## 준비하기

이 저장소의 작업 브랜치에서 아래 명령을 실행합니다. Python 3.10 이상이 필요합니다. Windows PowerShell에서는 `python` 대신 `py`를 사용할 수 있습니다.

```powershell
python -m pip install openpyxl pypdf
```

## 자료 넣고 확인하기

1. 새 엑셀 또는 ZIP을 저장소의 `work\` 폴더에 넣습니다. 폴더가 없으면 먼저 만듭니다.
2. 저장소 폴더에서 아래 명령을 실행합니다. 예시의 파일명을 실제 파일명으로 바꿉니다.

   ```powershell
   python scripts/import-video-research.py "work\새 역사 영상.zip"
   ```

3. 화면에서 읽은 파일·시트·행 수, 고유 영상, 기존 보고서 일치, 검토 후보와 자치구별 수를 확인합니다. `work/video-import/<파일 지문>/report.json`에서 시트별 조사 결과를 확인할 수 있습니다.
4. `git diff -- data/district-video-research.json`으로 공개 데이터의 추가와 변경을 검토합니다. 자료실에서 자치구나 장소를 검색하고 카드의 엑셀 출처에서 원본 파일·시트·행과 관련 장면을 확인합니다.

   ```powershell
   corepack pnpm test
   corepack pnpm typecheck
   corepack pnpm build
   ```

5. 승인된 공개 데이터만 커밋합니다. 원본 ZIP, 엑셀, 참고 PDF와 원본 열별 값은 작업 폴더와 원본 보관 위치에서 관리합니다.

## 시트 형식이나 중복 확인하기

- 가져오기는 여러 시트를 조사하되 누적 원자료를 기준으로 집계합니다. 장소, 구간, 권리 등의 보조 시트는 같은 자료ID의 조사 기록에 연결합니다.
- 새 파일은 `자료ID`와 `영상URL`이 들어 있는 30열 이상의 기준 시트 하나를 자동으로 선택합니다. 기준이 모호하면 공개 카탈로그를 그대로 두고 중단합니다. `scripts/import-video-research.py`의 `PRIMARY`에 파일명과 누적 원자료 시트명을 지정한 뒤 다시 실행합니다.
- 같은 파일을 반복 실행해도 같은 조사 기록은 한 번만 등록됩니다. 다른 파일에서 같은 영상이 나오면 조사 기록, 장소, 타임코드는 해당 영상 아래에 추가됩니다. 영상 식별자가 달라진 기존 조사 기록은 수동 검토가 필요합니다.
- `work/video-import/`에는 입력 파일별로 시트 데이터, 참조 PDF의 추출 텍스트, 조사 행과 보고서를 보관합니다. 원본 ZIP을 함께 보관하세요. 공개 JSON에는 검색과 출처 표시에 필요한 항목을 저장합니다.
- 정상 완료하면 공개 JSON 한 파일을 교체합니다. 실행 중 오류가 발생하면 메시지를 확인하고 입력을 수정해 다시 실행합니다. 프로세스가 강제로 종료되어 잠금 파일이 남은 경우 실행 중인 가져오기가 없음을 확인하고 `work/video-import/import.lock`을 삭제합니다.
- 사이트에는 조사표에 적힌 상태와 링크를 표시합니다. 영상 설명란에 있는 미검증 목차 시각은 출처 메모에 표시합니다. 영상의 재생 가능 여부, 장소와 건물의 직접 관계는 별도 검증 대상으로 취급합니다.
