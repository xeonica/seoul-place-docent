기준 main은 6436b56이다. 지침에는 이미 출처를 혼용하지 말라는 규칙이 있었지만 코드가 이를 강제하지 않았다.

1. photoResearchImageCandidates는 파일 확장자·기관 도메인·기관 ID로 URL을 생성했다. 특정 기록과 특정 파일의 연결 증거를 요구하지 않았다.

3. sceneSource/guidePhotos는 장면 제목·날짜와 첫 표시 가능 사진을 조합했다. 갤러리는 HTTPS URL만 있으면 표시하고 alternateUrls를 순서대로 시도했다.
4. 원본 URL과 권한이 불명확한 상태를 구분하는 공통 검증 결과가 없었다. 프록시의 도메인 허용 목록은 기록과 자산의 동일성을 보장하지 않는다.

## 검증의 의미와 제한

VERIFIED는 특정 기록과 특정 이미지 자산의 직접 연결 및 현재 설정한 표시 권한 검사가 통과했다는 뜻이다. 역사적 사실 전체의 의미 검증이나 현재 네트워크 접근 성공을 뜻하지 않는다. 실제 접근·MIME·용량은 이미지 전달 요청에서 검사하고 실패하면 표시를 중단한다. 갤러리는 다른 자산으로 대체하지 않는다.

근거는 기존 기관 수집 산출물이다. 서울역사박물관은 원문에서 수집한 fileId/fileSn 관계와 개별 공공누리 1유형을 사용한다. 서울기록원·성북은 상세 페이지의 실제 이미지 주소와 명확한 개별 권리를 요구한다. 목록 사진·파일명 유사도·동네 이름으로 승인하지 않는다. 원문 이용주기에 추가 협의가 있거나 공공누리 유형이 불명확하면 자동 승인하지 않는다. 권리 침해라는 법적 판단을 내린 것이 아니라 자동 표시 근거가 부족한 상태다.

originalImageUrl은 프록시 전의 기관 제공 이미지 URL이다. 기관이 제공한 미리보기/렌디션일 수 있으며, 아날로그 원판이나 최고 해상도 파일 확보를 뜻하지 않는다. full-resolution 원본과 무관한 URL을 추측하지 않는다.

빌드 색인에는 14,039개 원문-자산 증빙이 생성됐다. 이는 고유 사진 수나 실시간 접근 성공 수가 아니다. 현재 수집 사진 입력 행에서 박물관 7,295행 중 7,008행은 표시 조건을 유지하고 287행은 원문 링크만 제공한다. 기록원 2,322행과 성북 2,223행은 현재 증빙·권리 정보로 자동 표시하지 않는다. 모든 원본 파일과 URL, 설명은 저장소에 그대로 보존했다. 새로 확인된 기관의 직접 자산 정보·개별 권리를 기존 수집 파일에 반영한 뒤 색인을 재생성하면 검토 가능한 경로다. 검증되지 않은 사진 URL을 DB에 넣지 않았다.

- 전체 테스트 339개 중 322개 통과, 17개 실패. 기준 main 비교 실행은 329개 중 311개 통과, 18개 실패였다. 기존 권한 검사 1개를 합성 증빙으로 재현하도록 고쳐 통과했다. 남은 17개는 기준 main에도 있던 자료실 비동기 호출 오류, 자료 수 기대값·원본 해시 등의 실패다. 테스트 삭제·비활성화는 하지 않았다.
- TypeScript 검사 통과. Next.js webpack 홈페이지 빌드와 독립 MCP Vite 빌드 성공. MCP 빌드의 기존 inlineDynamicImports 폐기 예정 경고가 있으나 빌드는 성공했다.
- 실제 Chrome/모바일/Claude/ChatGPT 화면을 통한 검사는 수행하지 않았다. 갤러리의 실제 스크립트를 모의 DOM에서 실행했고 홈페이지 실제 TSX 컴포넌트를 React 서버 렌더링하여 img 포함 여부를 검사했다. 사용자 화면에 실제로 표시됐는지는 서버 로그만으로 보증하지 않는다.

## 운영과 잔여 위험

새 환경변수·외부 서비스·DB 마이그레이션은 없다. BigQuery/D1/R2 연결과 운영자 AI 비용 구조를 변경하지 않았다. 독립 MCP와 홈페이지 둘 다 수정했으므로 각각 재배포가 필요하다. 검토·병합 승인 후 기존 Vercel 빌드 경로(`pnpm build:vercel`, 독립 서버는 기존 `build:mcp-public:vercel`)로 배포하면 공통 검증 색인이 자동 생성된다. 이 작업에서는 main 병합·Production 배포를 수행하지 않는다.

외부 ChatGPT/Claude가 MCP와 별도로 이미지 검색을 실행하거나 지침을 따르지 않는 동작은 이 서버에서 완전히 차단할 수 없다. 서버가 반환한 검증 URL 외의 사진을 특정 기록 사진으로 소개하지 않도록 지침을 강화했지만 클라이언트 자체의 검색 결과·본문 편집은 별도 검증이 필요하다. 일반 현대 풍경 사진도 역사 기록의 이미지와 명확히 구분해야 한다.
