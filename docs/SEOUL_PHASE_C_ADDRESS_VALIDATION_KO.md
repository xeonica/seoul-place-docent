# 서울 25개 구 Phase C 주소 표본 검증

확인 기준일: 2026-11-22  
작업 기준 커밋: `8a8b630` (PR #78의 Phase C.1 시작점)

## 요약

CSV의 125개 슬롯을 유지하며, 시작 시 공식 확인된 51건의 이름·주소·공식 레코드 식별값을 그대로 보존했다. 이번 조사에서 공식 원문 개별 레코드의 명칭과 소재지를 대조한 항목 11건을 추가해 62/125건이 주소 확인 상태다. 남은 63건은 공식 개별 레코드 확인이 끝나지 않아 미확인으로 유지했다.

|---|---:|---:|---:|
| 아파트 | 15 | 10 | 25 |
| 시장 | 4 | 21 | 25 |
| 학교 | 9 | 16 | 25 |

| 공공건물(자치구청) | 25 | 0 | 25 |

주소 확인은 해당 장소의 공식 소재지 확인만 의미한다. MCP 장소 식별, 건물·필지 역사자료의 직접 연결, 기사·사진·영상 원문 검증 또는 이용 권리 승인을 의미하지 않는다. 이들 관계 필드는 계속 `not_measured` 상태다.

## 기존 공식 확인 51건 보존

시작 커밋 `8a8b630`의 CSV와 현재 CSV를 비교했다. 기존 51개 행의 장소명, 도로명·지번 주소, 공식 레코드 ID, 원문 URL은 모두 동일하다. 추가 확인 11건만 기존 미확인 슬롯에 기록했다.

기존 출처는 이전 조사와 동일하다: 서울특별시 자치구 안내의 구청 소재지 25건, 서울시 공동주택 OA-15818 아파트 15건, 학교 공식 자료 8건, 서울시 전통시장 OA-23058 및 자치구별 인허가 자료의 시장 3건이다. 각 행의 상세 식별자와 원문 위치는 CSV 필드에 유지되어 있다.

## 잔여 미확인 63건과 접근 한계

| 유형 | 미확인 | 이번에 진행되지 않은 이유 |
|---|---:|---|
| 아파트 | 10 | OA-15818의 DB 미리보기 소개와 검색 색인만으로 남은 각 단지명·주소·K-아파트코드 조합을 원문 개별 행까지 안정적으로 확인하지 못했다. |
| 시장 | 21 | OA-23058의 데이터셋 설명은 확인했지만 남은 후보 각각의 시장명·주소를 담은 개별 행을 확보하지 못했다. 인허가 레코드가 시장 자체가 아니라 입점 업소를 가리키는 경우는 채택하지 않았다. |
| 학교 | 16 | 기존 후보별 공식 기본정보 행과 주소의 일대일 대조를 마치지 못했다. 학교명이 다른 부가자료의 일부 텍스트로만 나타나는 경우는 승격하지 않았다. |
| 역사적 장소 | 16 | 개별 국가유산 상세 원문까지 확인한 9개 구만 반영했다. 나머지 16개 구는 원문 개별 레코드를 아직 확보하지 못했다. |

[서울시 문화재 지정 현황 OA-15593](https://data.seoul.go.kr/dataList/OA-15593/F/1/datasetView.do)에는 `서울시 소재 문화재 지정 및 등록 현황.xlsx` 파일이 게시되어 있으나, 이번 검증 경로에서는 다운로드 파일의 실제 행을 열어 확인하지 못했다. 따라서 데이터셋 소개나 파일명만으로 장소·주소를 추가하지 않았다. 공식 XLSX를 열람할 수 있으면 다음 조사에서 나머지 문화유산 표본을 대조한다.

CSV의 `source_file_name`은 이번에 내려받아 확인한 파일이 없어 비워 두었다. DB형 원문은 데이터셋 URL, 레코드 ID 또는 원문 행 식별 기준을 기록했다. 원문에서 지번만 제공된 행은 도로명주소를 추정하지 않았다.

## 역사자료 연결 및 Preview

이번 작업은 장소 소재지 확인만 수행했다. 건물 직접 근거, 동일 필지 근거, 주변 자료, 동네 배경자료 및 기사·사진·영상 원문 연결은 `not_measured` 상태로 유지했다. Preview MCP를 호출하지 않았으며, 실제 Preview 주소·전용 D1 연결 확인도 하지 않았다.

## 테스트

`tests/seoul-125-address-validation.test.mjs`는 125개 행과 25×5 슬롯, 공식 확인 62건, 시작 시 확인됐던 기존 51개 ID 보존, 원문 출처·식별자·확인일·자치구 일치, 지번 주소만 제공된 공식 원문 처리, 미확인 후보의 상태 미승격을 검사한다.
