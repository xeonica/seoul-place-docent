# 서울 25개 구 Phase C 주소 표본 검증

확인 기준일: 2026-11-22  
기준 브랜치 커밋: `5805714` (Phase B.5)

## 요약

기존 125개 슬롯에 공개 원문에서 장소명과 도로명주소를 함께 대조할 수 있었던 주소 51건을 반영했다. 주소 확인은 장소 주소의 출처 확인이며, MCP 장소 식별, 건물·필지 역사자료 연결, 자료 권리 확인을 뜻하지 않는다.

|---|---:|---:|
| 아파트 | 15 | 25 |

나머지 74개는 공식 원문 행을 확인하지 못했으므로 이전 미확인 상태를 유지했다. 자치구별 확인 건수는 각 구의 자치구청 1건을 포함해 1~3건이다. 역사적 장소 25건은 모두 미선정이며, 22개 시장과 17개 학교 또한 공식 원문 레코드 확인이 남아 있다.

## 출처와 식별 방법

- 공공건물 25건: [서울특별시 공식 자치구 안내](https://www.seoul.go.kr/seoul/autonomy.do)에 표시된 각 구청 소재지. 출처 본문 구별 행의 줄 번호를 `source_row_locator`에 기록했다. 이 목록은 별도 레코드 ID나 지번을 제공하지 않아 해당 열을 비워 두었다. 이 유형은 구청 주소 확인을 위한 표본이며, 일반 공공시설 표본까지 대표하지 않는다.
- 아파트 15건: [서울시 공동주택 아파트 정보 OA-15818](https://data.seoul.go.kr/dataList/OA-15818/S/1/datasetView.do)의 개별 표본. `official_record_id`에 K-아파트코드를, `source_row_locator`에 원문 번호와 단지코드를 기록했다. 지번은 해당 원문 행의 법정동 및 나머지 주소를 사용했다.
- 학교 5건: 교육청 학교 기본정보의 표준학교코드(강북·용산·중구·광진·관악)를 확인했다.
- 학교 3건: 성북구 성신초등학교는 서울시 초등학교 기본정보에서 장소명이 확인되지만 기존 후보가 학교 두 곳을 함께 적은 값이어서 주소 대조 완료로 처리하지 않았다. 그 외 서대문구 서울고은초등학교는 집단급식소 인허가, 강서구 백석초등학교는 어린이보호구역 위치도, 강동구 천동초등학교는 시설 인허가의 공식 행으로 학교명·도로명주소를 대조했다. 이 원문들은 학교 기본정보가 아니므로 데이터셋명을 정확히 기록했다.
- 시장 3건: 종로구 동대문종합시장은 [서울시 전통시장 현황 OA-23058](https://data.seoul.go.kr/dataList/OA-23058/S/1/datasetView.do)에서 대조했다. 광진구 노룬산시장([OA-18706](https://data.seoul.go.kr/dataList/OA-18706/S/1/datasetView.do))과 은평구 연서시장([OA-18713](https://data.seoul.go.kr/dataList/OA-18713/S/1/datasetView.do))은 각 자치구 대규모점포 인허가 행의 시장명·도로명·지번주소 및 관리번호를 대조했다.

학교의 공식 상세 데이터셋 링크와 레코드 ID는 CSV의 행별 `official_source`, `official_record_id`, `source_row_locator` 필드에 기록했다. 내려받기 파일이 없는 DB형 자료는 `source_file_name`을 비워 두었다.

데이터셋의 주소 필드 중 원문이 지번 미제공, 주소 상세 미제공, 혹은 이름만 제공한 경우는 해당 필드를 비워 두었다. 주소 일치가 확인된 경우도 건물관리번호·PNU를 새로 만들거나 역사자료를 승인하지 않았다.

## 역사자료 연결과 Preview

이번 검증에서는 역사자료 색인, 승인 이력, MCP Preview 응답을 실증하지 않았다. 건물 직접 근거, 동일 필지 근거, 주변 자료, 동네 배경자료 및 사진·기사·영상 연결은 모두 `not_measured`로 유지했다. Preview URL 및 Preview 전용 D1 접근 정보가 확인되지 않아 실제 MCP 주소 검색도 미측정이다.

## 테스트

`tests/seoul-125-address-validation.test.mjs`는 125개 슬롯과 25×5 유형 구성을 확인하고, 공식 확인 행의 출처 URL·행 식별 정보·확인일·자치구 일치를 검사한다. 미확인 주소가 공식 확인 상태로 잘못 승격되지 않는지도 검사한다.
