# 서울 도슨트 7부 통합 구현 현황

작성일: 2026-11-22
작업 브랜치: `codex/seoul-docent-integration`
대상: PR #76 7부 해설 계약 + PR #77 장소 연결 파이프라인

## Phase A 구현

- PR #76의 `DocentTourV2Schema`와 결정적 7부 자료 배정기를 현재 PR #77 MCP 경로에 연결했습니다.
- `prepare_place_answer`의 기존 텍스트 결과와 입력 도구 계약은 유지하고, `structuredContent`에 `tourPlan`을 추가했습니다. 기존 `photos` 키도 유지합니다.
- 관리형 AI 호출은 추가하지 않았습니다. `tourPlan`은 사용자의 AI가 해설을 쓸 수 있도록 근거·사진·영상 ID와 지침만 제공합니다.
- 질문의 초점이 건물 연도·사진·지명 등으로 좁혀지면 `focused_question`을 반환하고 7부 전체를 강제하지 않습니다.
- 각 부는 `supported`, `partial`, `missing` 상태와 누락 사유를 담습니다. 직접 건물·필지 근거가 없으면 4부에 미확인 사유를 남깁니다.
- 사진은 표시 권한 검증 상태와 매체 ID가 있는 자료만 할당하며 전체 8장 이하입니다. 영상은 최대 3개이며 검증된 구간이 없으면 시각을 만들지 않습니다.
- D1 장소 링크는 `usableAsDirectEvidence` 승인, 원문 근거 문자열, 관계 검토 상태를 모두 만족하는 경우에만 직접 근거로 변환합니다. 나머지는 후보로 유지합니다. 동네·주변·자치구 관계를 직접 장소로 승격하지 않습니다.
- PR #76 브랜치에서 과거 코드 의존 파일 `brief-docent.ts`와 `docent-experience.ts`는 복구하지 않았습니다. 롤백 이후 현재 계약에 맞춰 필요한 관계 우선순위를 독립 구현했습니다.

## 검증된 범위

- 15개 7부 구조·매체 배정·누락 사유·승인 관계 통합 단위 테스트 통과.
- MCP HTTP·라우트·아카이브 장소 링크 관련 32개 테스트 통과.
- 기존 주소 검증 CSV에 25개 구 × 5개 주소, 총 125개 행이 있고 주소 후보 일치 결과는 125건입니다. 표본 유형은 구청·도서관·초등학교·시장·주민센터입니다. 아파트·역사적 장소 표본 추가와 역사자료 연결은 확인되지 않았으며, 주소 인식을 역사자료 검증으로 간주하지 않습니다.
- `pnpm run typecheck`, `pnpm run build:mcp-public`, 별도 `.next-integration` 출력 경로의 Next.js Production 빌드 통과.
- 전체 테스트 354개 중 336 PASS, 18 FAIL. 앞서 기록된 PR #77 기준 실행도 18 FAIL이었고, 이번 실패는 조사자료·사진 fixture/외부 HTTP 관련 영역입니다. 이전 실패 로그와 테스트별 결과를 대조하지 못했으므로 “동일한 18개”로 단정하지 않습니다.

## 미완료 범위

이번 구현은 통합 기반인 Phase A입니다. 지명·사건의 원문 검증을 새로 수집하는 Phase B, 최신 도시계획 자료인 Phase C, 요청된 장소 유형별 125개 이상 실주소 실증 및 성능 계측인 Phase D는 완료하지 않았습니다. 서울 25개 구에 건물 직접 역사자료가 모두 존재한다고 가정하지 않습니다.

실제 의미 대조는 수행하지 않았으므로 모든 계획의 `semanticVerification`은 `not_checked`로 유지됩니다. 최종 문장 생성자는 계속 사용자의 AI입니다.
