## 수집 현황
- 서울기록원 여의도 시정사진 컬렉션(https://archives.seoul.go.kr/photo/collection/detail/67)에서 개별 상세 URL 9개 확인. 이 중 GitHub 검색에 IT 문자열 검색 결과가 나온 3개(IT240, IT241, IT2393)는 중복 여부 확인 전까지 보류. 검색 결과 없는 6개를 CSV에 기록.
- 확보·저장 6개, 공식 개별 메타데이터 B등급 6개. GitHub 검색상 명확한 일치 없음(전수 확인 아님). 이전 수동 조사에서 확보한 국회의사당 3개와는 URL이 다름.
- 여의도 전체 도시 배경 자료이며, 국회의사당 본관 건물 자체의 직접 사진으로 취급하지 않음. 관련주소ID는 공란.
