## 운영 반영 전 필수 확인

1. 운영 D1 `archive_sources`의 기존 URL·기관 ID 중복 조회
2. 공식 상세 서지와 장소 범위 최종 대조
3. 자료별 `rights=unknown`, `storageAllowed=false`, `reuseAllowed=false` 유지
4. 사진·PDF 원본과 인용·전사 본문은 등록하지 않음
5. 권한 있는 운영 관리자에 의한 검토 및 등록 후 MCP 조회로 확인

이 목록의 '서지 확인'은 '저작권 활용 승인'이나 '운영 반영 완료'를 뜻하지 않습니다. 나머지 조사 대상은 별도 누적 검토 CSV `seoul_docent_cumulative_20261115_2100.csv`(50행)에 보존되어 있으며 이 PR에 합치지 않습니다.
