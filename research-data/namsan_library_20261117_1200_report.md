# 남산도서관 및 인접 공간 역사자료 조사 (2026-11-17 12:00 회차)

## 대상
- 마스터 CSV 확인: 203,850개 후보 중 `SPOT-IND-YSD-001` 서울특별시교육청 남산도서관, 용산구 후암동, category IND.
- 마스터의 역사 설명은 검증 근거로 사용하지 않고 공식 기록과 대조했다.

## 성과
- 공식 개별 상세정보가 확인된 후보 5건: A 0 / B 5 / C 0.
- 도서관 자체 직접 관련 2건, 인접 공간 3건. 공식 개별 기록 5건이며 사진 컷 수를 기록건으로 합산하지 않음.
- 조사 과정에서 별도 확인한 공식 배경 자료: 서울기록원 남산공원 연구 가이드(https://archives.seoul.go.kr/research-guide/2000)와 서울기록원 시정사진 목록. 개별 기록으로 집계하지 않음.
- 기존 GitHub 코드 검색에서 '남산도서관'은 정독도서관 보고서에서만 검색되었고, 두 서울기록원 기관자료ID(RG5-SR63-IT2823, RG5-SR79-IT215)는 직접 검색 일치가 없었다. 다만 GitHub 검색 색인에 잡히지 않은 CSV/대량 데이터가 있을 수 있어 **전체 저장소 신규성 미확정**. 확인된 중복 제외 0건, 전수 대조 미완료.
- 50건 목표 미달: 공식 개별 기록 상세정보를 확인한 5건만 기재. 사진아카이브 전체 목록 및 타 기관 검색 범위의 전수 확인은 미완료.
- 이용조건: 서울기록원 기록 2건은 공개/이용유형 제한없음 표기가 있으나 네거티브필름은 서울역사박물관 협의 필요. 서울역사박물관 기록 3건은 공공누리 제4유형 표시. 사이트·썸네일·임베드·변형·원본보관 **승인 0건**, 전건 개별 활용 심사 대기.
